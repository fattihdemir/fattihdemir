# About Me

I am a Backend Software Developer focused on creating performant, resilient, and highly customized system architectures. While specializing deeply in the **.NET & C#** ecosystem for core backend workflows, I build cross-platform desktop experiences and systems tooling using **Rust** and **Tauri**. 

My engineering discipline revolves around writing decoupled, high-performance, and structural source code. I frequently look past standard web applications to engineer otonom automation environments, customized toolsets, local data layers, and hardware-software interfaces.

---

## Featured Architectural Focus & Repositories

### Intelligent Agents & Custom Tooling
* **Autonomous Multi-Agent Systems:** Architecting decoupled multi-agent frameworks leveraging local LLM orchestration (via LM Studio) to handle sequential software engineering tasks. 
* **Custom Extensions:** Designing specialized IDE infrastructure—like the *Agent Companions* ecosystem for VS Code—integrating local inference capabilities directly into developer workflows.

### Native Desktop & Tools
* **Rust & Tauri Applications:** Leveraging Rust's memory safety and Tauri's lightweight runtime to build performant, secure, and low-overhead cross-platform desktop interfaces.
* **LocalForge / Local Infrastructures:** Building lightweight local database abstractions, persistent key-value storage wrappers, or environment orchestration layers designed to optimize workspace performance.

### Systems Programming & Hardware Simulators
* **Low-Level Algorithmic Optimization:** Engineering complex recursive routines, customized memory management patterns, and optimized deterministic sequences in pure **C** without structural overhead.
* **Digital Logic Systems:** Simulating discrete hardware logic, 7400-series IC matrix layouts, and signal processing workflows using Proteus, Wokwi, and raw timing diagrams.
